## Public transcription

The [questionnaire](household-energy-questionnaire.md) preserves the latest draft's visible question text and answer options. It adds Q01–Q41 identifiers, Markdown headings and list formatting. Comments and deleted tracked text are not included in respondent-facing content.

The inline researcher explanation following the building-age question is presented here instead of inside the survey:

> Building age was proposed as a proxy for construction standards and energy-efficiency requirements. Its relationship to heating demand and insulation would need to be considered in the implemented study.

This is a paraphrase of a drafting note, not a validated finding from this project.

## Design questions to resolve before fieldwork

| Issue in the supplied draft | Further design work |
|---|---|
| The household-member table has only three displayed rows | Define a repeatable section for households of any size |
| “Black or African American” and “Hispanic” appear in a UK-targeted survey | Review the demographic categories for the intended UK population and research purpose |
| Some housing and working-pattern questions mix household and individual perspectives | Specify the unit of response and how household members are represented |
| Some questions appear to allow multiple answers without explicit selection instructions | Define single-choice versus multi-select behaviour |
| Ranges, optional answers and branching are not fully specified | Confirm units, non-overlapping boundaries, “prefer not to say”, “don't know” and skip rules |
| Some attitude choices combine beliefs, willingness and ability to change | Test whether these need separate questions to avoid conflating constructs |
| Sensitive fields and outward postcode appear in the instrument | Define their research purpose, handling and appropriate aggregation before collecting responses |
| Appliance efficiency wording reflects the source draft | Review the terminology and categories for the survey's eventual fieldwork date |
| No participant information or consent page is supplied with these drafts | Prepare the study information, consent and relevant review process before recruitment |

These are repository review observations added in October 2026. They describe possible improvements to an existing draft; they are not evidence of completed revisions or an approved study.
