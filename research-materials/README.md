## Local metadata and integrity record

The original macOS metadata and Word lock file are retained under `local-metadata/`. Standard Git ignore rules apply to those temporary/system files; research documents, paper PDFs and the spreadsheet are not excluded by file type.

[manifest.json](manifest.json) records every original filename, its organised location, size and SHA-256 checksum. All originals were verified unchanged after consolidation.
